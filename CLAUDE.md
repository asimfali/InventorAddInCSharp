# CLAUDE.md

Роль: разработчик надстройки (add-in) для Autodesk Inventor 2021 на C# (.NET Framework) — проект `Macros`.
Общение — на русском.

## Сборка и проверка

- Собирает и запускает пользователь сам: Visual Studio + Inventor 2021 (Ctrl+F5). Windows-решение из WSL не собирать.
- Допустима только проверка компиляции отдельного файла (например, `GlbExport.cs`) Framework-овским `csc`
  против interop Inventor из GAC и `custom.dll` во временной папке.
- Interop Inventor встроен (`EmbedInteropTypes=True`): у коллег Inventor 2021.1, у пользователя 2021.2.
- Спорный подход — сначала обсудить. Утверждения о геометрии моделей (какие грани сплайны, какие цилиндры и т.п.)
  проверять по данным (`_debug_*.txt`, выгруженные GLB), а не предполагать.

## Экспорт в GLB (`GlbExport.cs`)

Меню «Общее» → «Экспорт в GLB (одно тело / сборка)», обработчики в `Parts.cs`. Результат — в папке `glb` рядом с моделью
(+ `_report.txt`, `_progress.txt`).

- **Одно тело (Single)** — внешний вид для сайта: только видимое снаружи, один меш.
- **Сборка (Assembly)** — для сборщиков в просмотрщике портала: иерархия вхождений, все детали (в том числе внутренние),
  одинаковые тела — один меш на много узлов. Модель должна быть минимальной — у сборщиков слабые компьютеры.

## Справочные репозитории (только чтение)

- `~/develop/filter-app` — фронтенд портала (React + three.js). Просмотрщик моделей для сборщиков:
  `src/pages/model-viewer/` (`useModelViewer.js` — загрузка и отрисовка, `utils.js` — дерево узлов).
  Что там важно для экспорта:
  - GLB грузится `GLTFLoader` через `/api/v1/media/download/?path=...`.
  - Все материалы заменяются на `MeshBasicMaterial` (цвет, `transparent`, `DoubleSide`): освещения нет,
    текстуры/металличность/шероховатость из GLB не используются. Форму передают цвет и линии рёбер
    (`EdgesGeometry` с порогом 15°), которые строятся для каждого меша-объекта отдельно.
  - Ось Z — вверх (`camera.up = (0,0,1)`), как в Inventor.
  - Дерево в панели строится из имён узлов; скрыть/изолировать/цвет/прозрачность — по объектам `Mesh`
    (меш из нескольких примитивов становится группой дочерних `Mesh`).
